## 5. 条目 ↔ 摘要 的对应（真机核过）

| 向量条目侧 | 摘要页签侧 | 说明 |
| --- | --- | --- |
| `metadata.index` = `sum_s-0240-0253-6.md` | 文件名 `s-0240-0253-6.md` | 去 `sum_` 前缀即主键 |
| `metadata.tags`（`pt:<周目id>` 即归属） | 标签 | 归属徽标由此算出 |
| `metadataFile`（`<uuid>.json`） | — | 库里只存向量，正文单独放；展开区显示正文预览 |
| `chars`（正文文件 `text.length`）/ `timestamp` | 摘要页签的 chars/createdAt | 向量侧没有这两个字段；字数=**切片**字数（与摘要全文字数口径不同，展开区并排给出） |
| 楼层 / 摘要全文字数 | `summaries/index.json` 的 `fromFloor/toFloor/chars` | 复用「摘要」页签**同一份读法**（`archivePath + '/summaries/index.json'`），没有另造第二套；读不到则对应列如实写「『摘要』页签里没有这条对应的文件」 |
