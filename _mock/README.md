# _mock · Agent 编辑器视觉方案（第一步交付物，未动任何插件代码）

**打开方式**：双击 `agent-editor-visual.html`（单文件、无外网依赖、1280×860 与真机面板同规格）。

## 页面顶部 6 个演示按钮 = 计划书 §2 要求的 6 个状态

| 按钮 | 演示什么 |
|---|---|
| ① 默认态 | 未选会话：引导空态 + 灰显地图骨架（不再是一片「未知」） |
| ② 地图填充 | 轮次条 + system/tools/messages 三框 + 红/黄/蓝/灰虚线色块 + 静态/每轮 |
| ③ 色块下钻 | 点 system 框的 persona 块 → 看该段原文（搜索/复制），替代常驻「部件查看」列 |
| ④ 维护展开 | 顶栏「🛠 维护」→ 右侧抽屉：生成预设 / 修复 / 备份与应用 / 4 旋钮 |
| ⑤ 次数三形态 | 会话列表行尾徽标：「—」未解析 / N 解析成功 / ⚠ 失败（绝不画成 0）/ 0 确实为 0 |
| ⑥ 错误态 | 数据面不可用 + preset 读不到：不渲染假地图、如实说读不到 |

可切换「显示对照标注」：每个区块挂有 **原组件 + 行号 + 留/去/收起** 的黄/绿/红/蓝角标。
勾掉后是干净的目标形态预览。
